# 开拓者（Trailblazer）包

来源：`pet_reference/开拓者/`（Spine 4.2.40 JSON 导出，皮肤 default，105 骨骼）。
三件套已改名：`trailblazer.json` / `trailblazer.atlas` / `trailblazer.png`。

## 需求原文（2026-10-07 恢复自会话数据库，防再次丢失）

> 我有一个想法。需要给动画进行一些更改。列入计划
> 0. 我希望idel能融入emoji_0的眨眼动作。
> 1. 我希望emoji_1的眼睛和嘴巴和idel结合，作为快捷按钮的触发的表情（备忘提醒、待办推荐、定时提醒）
> 2. 我希望有一个垃圾桶素材，在长待机进入睡眠模式后，开拓者躲进垃圾桶里。点击后会快速顶开垃圾桶盖子（动作上垃圾桶盖子有自然的快速摆动），露出半个头，此时的表情是emoji_1的眼睛和嘴巴与idel结合持续一小段时间，随后变成正常idel表情，持续一段时间。整段顶开垃圾桶的时间中途有自然的身体摆动。并且在该状态下再点击就跳出垃圾桶变回正常idel，如果该状态下一段时间没有再点击就缩回垃圾桶（也需要垃圾桶盖子的摆动）。长待机在垃圾桶中时，快捷按钮正常触发，但是点击备忘提醒、待办推荐、或者完成定时提醒的设置后，开拓者快速顶开垃圾桶盖子，与该点击状态、动画相同，也可以期间内再次点击脱离垃圾桶。
> 3. 关于脱离垃圾桶，我希望是开拓者快速缩回垃圾桶后的瞬间垃圾桶炸开，开拓者使用emoji_1和idel结合的表情持续一段时间，然后回到正常的idel，进入普通待机状态。

## 骨架内置动画

| 动画 | 时长 | 内容 |
| --- | --- | --- |
| idel | 3.33s | 待机循环（56 骨骼轨道 + 2 IK）。注意源文件拼写就是 `idel` |
| emoji_0 | 3.33s | FACE-1 网格闭眼变形（t≈1.33–1.67s）。emoji_3/4 与其逐字节相同，忽略 |
| emoji_1 | 0.1s | 瞬时表情切换：FACE-1→FACE-2、YAN-OO→YAN-XX、ZUI-1→ZUI-5，隐藏腮红/睫毛 |
| emoji_2 | 0.1s | 瞬时表情切换：FACE-1→FACE-2、ZUI-1→ZUI-3，隐藏腮红/睫毛 |
| emoji_5 | 3.33s | 嘴型切换 ZUI-1→ZUI-5 后回弹 + FACE-1 变形 |

## 交互规格（长待机垃圾桶）

| 操作 | 行为 |
| --- | --- |
| 挂机 `sleepAfterMinutes`（1 分钟） | `入桶` → `桶内待机` 循环 |
| 桶内**点击**（第 1 次） | `顶盖张望`（仍在桶内，盖子绕头顶接触点摇摆） |
| 张望期间**再点击**（3.0s 激活窗内） | `跳出炸开` → 普通待机 |
| 张望 3.0s 后点击 | **重新张望**（张望视觉约 3.0s 结束，激活窗同步；之后点击不误触跳出） |
| 桶内**拖动** | 保持桶态（拖动期间沿用桶动画）；**松手**触发 `顶盖张望` |
| 桶内点快捷按钮（备忘/待办/提醒） | 同 `顶盖张望`（`peekWhileSleeping` 语义：气泡隐藏回桶内待机，不唤醒） |

## 动作映射与垃圾桶状态机（manifest.actions）

- `idle`/`idleBase` → `idel`（已融入 emoji_0 眨眼）
- `sleep` → `入桶`（一次性）→ 渲染端队列 `桶内待机` 循环
- `wake` → 睡态点击走行为引擎判定：首次=张望、张望窗内=`跳出炸开`（经 state.animationName 通道，播完归位普通待机）
- `cheer`/`alarm` → `idel_emoji1`（清醒态）；**睡眠态**由 behavior-engine 覆盖为
  `顶盖张望`（一次性，回桶内待机）——备忘提醒/待办推荐/定时提醒三按钮共用
- 生成脚本 `tools/trailblazer/add_bin_animations.py`。收缩机制（关键）：
  不开新骨骼/不重排/不重父级（**加权网格按骨骼下标绑定，任何插入重排都会让
  网格全部绑错骨 → 渲染成乱码**）。收缩 = `身体` scale S + translate
  (1−S)·(G−B0)（关于地面锚点的精确相似变换），并对**所有不吃父级缩放的
  骨骼**（inherit ∈ noScale/noScaleOrReflection/onlyTranslation，含无槽位的
  加权辅助骨）补 scale=S。注意 `noRotationOrReflection` **会**继承父级缩放，
  不能补（否则 0.62² 双重缩小）。4.2 线格式：rotate 键 `value`、双属性 curve
  必须 8 数绝对坐标（4 数会静默产出 NaN）。transform 约束保持启用（禁用会让
  头发错位）。SHEN-WT-2（外套下摆）隐藏态淡出
- 盖子骨骼原点（旋转轴）在骨架层上移至**头顶接触点**（`LID_PIVOT_RISE`，attachment
  偏移抵消、外观不变），张望摇摆绕头顶；盖中心对齐头顶冠部 `LID_SHIFT_X`
  （骨骼局部，父级 ×2）。盖子放大 1.19×（桶口沿条 575px vs 盖 514px）
- 相机取景：manifest `cameraExcludeSlots` 排除桶三槽（运行时 getBounds 不检查
  alpha，否则相机被撑远、角色变小）；`cameraExtend.top=360` 为张望时高举的
  桶盖预留顶部空间（盖子峰值 y≈1915 vs 未扩展可见顶 1567，否则被舞台边缘截断）。
  扩展会使取景放大 zoom（宠物视觉缩小 ~17.5%），已用 `petScales.trailblazer`
  0.6→0.73 补偿
- 点击映射：`actions.click = idel_emoji1`（点击=表情一次性播放，2.3s 后回常态）。
  注意渲染端 click 分支的**随机池只在包未声明 click 时生效**（`packActions['click']`
  判定）——否则池被排空后会回退全局常量 `抬手示意` 导致点击无反应

### 动画清单（生成）

| 动画 | 时长 | 循环 | 内容 |
| --- | --- | --- | --- |
| 入桶 | 1.9s | 否 | 桶淡入 + 角色收缩沉入（脚贴地，0.62）+ 盖子落下回弹摆动（盖子放大 1.19× 盖满桶口） |
| 桶内待机 | 3.33s | 是 | 桶体呼吸（盖子静止不晃动） |
| 顶盖张望 | 3.4s | 否 | 盖子**举到头顶上方**（小幅摆动）、只露头部（头+发放大 1.25×、表情 emoji_1→回正常）→缩回合盖 |
| 跳出炸开 | 2.4s | 否 | 下蹲→盖子炸飞自转淡出（0.3→0.75s）→弹出落地回弹→**桶随即淡出（0.15→0.85s 即开始）** |
| BIN校准 | 0.2s | 是 | 标定用（不进 manifest） |
