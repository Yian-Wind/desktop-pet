# Promeia Spine Pack

普罗米娅 Spine 桌面宠物皮肤包（背手姿态版）。

## 安装

将 `promeia_back/` 整个目录解压到应用的 `packs/` 目录下，重启应用或在皮肤切换菜单中选择 Promeia 即可。

## 文件说明

- `promiya_back.json` — Spine 4.2 骨骼数据（含全部动画）
- `sp.atlas` + `page.png` — 纹理图集
- `manifest.json` — 包声明（应用读取，含动画列表与资源路径）
- `corpus.json` — 交互语料（点击/拖拽/睡眠等台词，含触发分钟数）
- `persona.json` — 角色设定（名字与描述）

## 动画

| 动画 | 说明 |
|---|---|
| `eye` | 待机眨眼（呼吸微动），循环播放 |
| `背手` | 切换到背手站姿；大衣在 0.06s 内淡入 |
| `解背手` | 从背手姿态回到正常站姿；大衣在 0.053s 内淡出（起点 0.12s） |
| `刃舞` | 待机表演：双刃以掌心为轴原速环绕 25 秒，前臂在表演期间交叉淡入为刃舞专用素材 |
| `发光呼吸` | 内部循环动画（不进 manifest）：背手姿势保持期间马尾发光槽位的正弦呼吸，由渲染端在 track 1 驱动 |

## 交互行为

- **点击**：在「正常站姿 ↔ 背手站姿」之间循环切换，切换动画播完后停帧保持当前姿态（含大衣显隐），不会被眨眼打断
- **拖动**：姿态保持停帧不变，头部切换为闭眼表情；松手后立即恢复睁眼，姿态原样保留
- **落地**：无挤压回弹效果，直接稳定落地（本包仅 `default` 单皮肤）
- **待机**：约每 4 秒眨眼一次（应用设置可调）
- **睡眠**：`corpus.json` 的 `sleepAfterMinutes`（当前 1 分钟）后入睡；入睡不改变站姿（背手/解背手停帧原样过夜，且不叠加马尾发光）
- **待机表演**：入睡后按应用设置的睡眠动画间隔（默认 30 秒）轮播 `刃舞`；普通待机与背手保持期间不表演

## 渲染细节（供集成参考）

- 骨骼为 Spine 4.2 导出（`spine: 4.2.35`），需 4.2 系运行时加载
- 闭眼表情通过 `head` 槽的 `head_eye_eyeclosed` 附件切换实现（与睁眼头附件中心已对齐），非骨骼变形
- `coat` 槽 setup 值为全透明（`ffffff00`），大衣显隐完全由 `背手`/`解背手` 动画的时间线驱动
- 马尾发光呼吸作用在 `ponytail_illuminate` 槽位（track 1 循环 `发光呼吸`）；离开背手姿势时从当前亮度 0.6s 淡出后清轨道
- 姿态切换前需清空轨道并重置到 setup pose，避免上一姿态残留叠加
- 像素命中判定基于 WebGL readPixels（alpha > 8）
